# Нумерологические системы анализа

## 🔢 Классическая нумерология (Пифагор)
**Базовый расчет:**
- `Число Жизненного Пути` = сумма цифр даты рождения (редуцируется до 1-9)
- `Число Судьбы` = числовое значение полного имени
- `Число Экспрессии` = вибрация личности

**Применение:** анализ врожденных качеств и потенциала.

## ♾️ Кармическая нумерология
**Основные показатели:**
- `Кармические числа` (13, 14, 16, 19)
- `Недостающие цифры` в числовой матрице

**Использование:** выявление повторяющихся жизненных сценариев.

## 🌌 Ведическая нумерология
**Ключевые принципы:**
- Планетарные соответствия (1=Солнце, 2=Луна,...,9=Марс)
- Система `Числа Раши` (астрологическая совместимость)

**Применение:** выбор благоприятных периодов.

## Сравнительная таблица

| Система       | Источник данных     | Основной инструмент |
| ------------- | ------------------- | ------------------- |
| Пифагорейская | Дата рождения + имя | Числовая матрица    |
| Кармическая   | Числовые паттерны   | Анализ "пробелов"   |
| Ведическая    | Планетарные связи   | Граха-нумерология   |

> Для самопознания используйте классический метод, для работы с повторяющимися ситуациями - кармический, для выбора дат - ведический.
